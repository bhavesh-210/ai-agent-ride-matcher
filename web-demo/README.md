# Public resume demo

[Open Roadwise](https://roadwise-bhavesh-demo.scenicboat64.chatgpt.site/)

This buildless demo explores **recorded outputs** for 20 requests, generated by the Python matching graph at source commit `244444ec0fb5876ef070f1e76ae9abc8f130bccd`. It does not run Python, make model calls or fetch live road routes in the browser. The original FastAPI demo runs the actual graph locally.

The snapshot omits rider identities and coordinates. Each candidate has its status, supplied ETA and audit reason. The source-ID no-match is preserved.

To serve this exact public demo locally:

```bash
python3 -m http.server 8001 --directory web-demo
```

Open http://localhost:8001. The demo also includes a guided bridge walkthrough, archived trace excerpts and a browser policy simulator. The simulator is tested against the Python graph for 60 scenarios; it is not a live Python or OpenRouter endpoint. The original hosted export source remains `98c5804d18e90484023abf0d79b7f3a16469c40c`.
