# Data provenance

`source/requests.csv` and `source/drivers.csv` are the supplied **Uber Ride Requests Test Set** and **Uber Candidate Drivers Snapshot** for the week of 3–9 March 2025, used in the project assignment. They are snapshot/mock data, not a live Uber integration. The project owner explicitly authorized publication for this submission. No affiliation with Uber is claimed.

There are 20 request rows and 80 candidate rows. Request `RQ-0308-018` has no exact candidate match; four candidate rows use orphan ID `RQ-0309-018`. The source is preserved as supplied. Never infer that the two IDs refer to the same ride.

The repository's MIT license covers the author's application code and documentation. It does not grant additional rights to third-party supplied datasets. Check the original resource provider's terms before reusing the source CSVs elsewhere. The hand-written JSON example fixtures are separate from those source CSVs.
